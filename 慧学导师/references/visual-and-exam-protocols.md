# 跨学科可视化图解规范、课件溯源精读与期末真题速成协议

> 蒸馏自慧学平台 `server/assistantSkills.js`、`server/examAI.js`、`server/documentAI.js`、`server/courseBlueprint.js` 与 `server/personalization.js`。

---

## 一、全学科可视化与排版协议

### 1. 告别纯文字墙
- 单段正文**不得超过 120 字**；优先使用短小分节、编号步骤、`>` 提示卡、Markdown 对比表（`| 对比维度 | 概念 A | 概念 B | 适用条件/易错点 |`）。
- 公式一律使用规范 KaTeX LaTeX：行内 `$...$`，独立公式 `$$...$$`；禁止出现裸 `√` 符号配断行分数。

### 2. 全学科图解选型指南（不限理科）
在输出中主动根据知识形态选用最贴切的图解（对话场景优先用合规 **Mermaid**；如需程序化前端渲染，可同时输出 **`visual-spec` JSON**，**严禁模型手写裸 `<svg>` 像素坐标**）：

| 知识形态 | 典型学科场景 | 对话输出推荐（Mermaid） | 程序化渲染类型（`visual-spec`） |
| :--- | :--- | :--- | :--- |
| 概念关系网 / 因果树 | 心理学流派关联、法学请求权关系、生物信号通路 | `flowchart LR`（带边标签） | `concept_map` |
| 易混概念多维辨析 | 民法善意取得 vs 无权处分、急性心梗 vs 主动脉夹层 | Markdown 对比表 + `flowchart` | `comparison_cards` |
| 演进脉络 / 诉讼程序 / 历史阶段 | 法律位阶、中外文学流变、项目生命周期 | `flowchart LR` / `timeline` | `timeline` |
| 解题决策流 / 系统状态机 | 算法分支、TCP 握手、SOAP 临床诊疗、审图流程 | `flowchart TD`（含菱形判断） | `flow_diagram` |
| 学科框架 / 分类层级 | 教材知识树、B+ 树结构、组织架构 | `mindmap` 或 `flowchart TD` | `structure_tree` |
| 会计复式记账 | 坏账准备、固定资产折旧、所得税递延分录 | Markdown 双栏表格 | `t_account` |
| 变化曲线 / 统计分布 / 平面几何 | 供需均衡移动、伯德图、函数极值、几何全等 | 关键坐标描述表 / Python 绘图 | `function_plot` / `geometry_plot` / `bar_chart` |

**Mermaid 防语法报错铁律**：节点文本只要包含中文括号 `()`、方括号 `[]`、冒号或斜杠，**必须加双引号**：`A["民法典（总则编）：核心条款"]`。

### 3. 程序化 `visual-spec` JSON 最小规范（供前端渲染器兼容）
```json
// 1) 概念关系网
{"type":"concept_map","title":"标题","center":{"label":"中心概念","sub":"简注"},"nodes":[{"id":"n1","label":"概念A","sub":"作用","group":"cause|core|effect|method|contrast"}],"edges":[{"from":"n1","to":"center","label":"关系"}]}

// 2) 对比辨析卡
{"type":"comparison_cards","title":"标题","items":[{"name":"对象A","badge":"核心","summary":"简述","points":["要点1","要点2"],"pitfall":"易混边界"}]}

// 3) 时间线 / 位阶线
{"type":"timeline","title":"标题","steps":[{"stage":"阶段/步","label":"要点","detail":"核心解释","tag":"标签"}]}

// 4) 流程图 / 体系树 / T型账 / 函数 / 几何
{"type":"flow_diagram","title":"标题","direction":"LR","nodes":[{"id":"n1","label":"输入","kind":"start"},{"id":"n2","label":"推演","kind":"process"},{"id":"n3","label":"结论","kind":"end"}],"edges":[{"from":"n1","to":"n2","label":"条件"}]}
{"type":"structure_tree","title":"标题","root":{"label":"核心概念","children":[{"label":"分支1"},{"label":"分支2"}]}}
{"type":"t_account","title":"T型账","accounts":[{"name":"应收账款","debit":[{"label":"确认收入","amount":"10,000"}],"credit":[{"label":"收回款项","amount":"10,000"}]}]}
```
**图形宁缺毋滥原则**：当原题几何图形/复杂电路/解剖图的关键方向或坐标无法从文字严格唯一确定时，**填 `null` 并提示对照原卷图**，绝不盲画交叉蝴蝶结或错位示意图。

### 4. 知识关联三元组
每个知识点结尾必须用 1–2 句显式标明：`前置依赖（Prerequisites）→ 本节核心 → 后续延伸（Leads To）`。

## 二、期末真题速成解析协议（Exam Crash Protocol）

当用户丢入往年真题、模拟卷或原卷参考答案时，严格执行以下保真规则（源自 `server/examAI.js`）：

1. **原卷参考答案 4 种形态自动解析**：
   - 表格型：`题号 1 2 3 / 答案 C B B`
   - 区间连写型：`1-5: ABCDA` / `6~10 B C D A B`
   - 行内多题型：`1.A 2.B 3.C 4.D`
   - 逐行型：`1．C`
   - *若存在原卷官方答案 `officialAnswer`，最终校对以原卷答案为准并明确标注「答案以原卷参考答案为准」*。
2. **选项保真与防篡改规则**：
   - 识别到 `A./B./C./D.` 原题选项时，**严禁擅自删改选项个数或乱改选项文本**；只允许用规范 LaTeX 美化排版（`cleanStem` 与 `cleanOptions` 分离，不把选项重复塞进题干）。
3. **缺原文 / 缺听力题诚实降级**：
   - 遇到听力题、阅读原文缺失或附图完全不可见导致无法客观定答案的题目，严禁蒙猜 `A/B/C/D`，必须标记为 **「自评题（`selfCheckOnly`）」**，明确写出「*原文/录音/题图不在输入中，无法客观定案，请对照原资料自评*」。
4. **期末包一键产出清单**：
   - 每道题输出：`📋 原题还原 → 🔍 考点定位 → 📊 图解/对比（可选）→ 📖 分步详解 → ✅ 参考答案与易错陷阱`。
   - 同时汇总产出：**🗺️ 全卷考点地图 + 🃏 高频记忆闪卡 + 📄 可打印《考前救命一页纸》**。

## 三、课件/PPT/教材精读与逐字溯源协议（Document Grounded Protocol）

当用户提供成页 PPT、Word 笔记或教材章节时（源自 `server/documentAI.js` & `server/source.js`）：

1. **碎片智能合并**：将过短的零碎 PPT 单页（如每页仅 150–300 字）按同章节语境合并为完整语义单元再讲解，避免只见树木不见森林；若遇到封面/目录/过渡页，诚实标为「原文导读」，不强行编造生硬考题。
2. **逐字原文引句溯源（`sourceQuote` 铁律）**：
   - 从资料生成知识点测验题或记忆闪卡时，**每一题/每一张卡片必须附带直接复制自上方资料的连续 ≥ 8 个字符的原文原句**（允许极少数全半角/标点规范化差异，但绝不允许改写或脑补）；
   - 引句与题干/解析必须在核心词上存在语义相关性。
3. **两层质量口径坦诚披露**：
   - 即使完成「原文引句存在性核查」或「同模型二轮自检」，仍需坦诚告知学习者：**结构校验与原文引句存在不等于教师级学科正确性证明，关键考试仍需对照原教材与任课老师讲义复核**；且不依据单份资料臆测未给出试卷的「考试频率」。

## 四、同考点变式巩固与定制课程蓝图规范

1. **同考点变式出题（`Variant Drills`）**：
   - 当学习者某题做错时，生成 1–3 道同考点变式题：**必须改变题目情境、前提数值或设问视角**，严禁只是调换 `A/B/C/D` 选项顺序假装新题！若用户仅要求巩固原题结构，再做明确标识。
2. **定制课程蓝图模式（`Course Blueprint Mode`）**：
   - 当用户已与导师协商确定好 `1–20` 个学习单元蓝图（含每个单元 `name` 与 `goal`、前置知识与结课实战项目）时：
   - 严格按照确认的单元顺序与逐字名称展开，不擅自擅增删改名；将各单元串联成直通**结课真实项目**的阶梯路径；未提供用户作品时不虚构成果。
