# 场景实战 2：跨专业零基础从 0 到登顶（终生学习导师模式）

> **典型痛点**：你是计算机/工科背景，现在想系统自学「心理学」或「法学」，或未来工作需要跨界掌握「量化金融」「临床医学常识」，网上资料零碎且专业黑话劝退，希望有人用高校级的培养方案带你一路走到专业高阶。

---

## 一、在对话中直接这样唤醒「慧学导师」

```text
请启用 huixue-mentor 的【系统登顶模式 + 费曼破壁模式】：
我本科是机械工程背景，完全零基础，想系统学习「心理学」（或「法学」），
目标不是看几篇鸡汤公众号，而是按正规大学本科到高阶实战的体系学透，最终能读懂核心论文并用科学方法分析实际案例。

请你：
1. 先运行 scripts/research-syllabus.mjs --major "心理学" --depth comprehensive 获取权威开源课程与 6 阶段 × 24 节点高校级蓝图；
2. 结合我的工科思维背景，给我展示第 1 阶段第 1 节（先讲机制再给名词 + 贴近工程直觉的生活类比与类比边界 + 黑话对照表 + 概念关系图）；
3. 每学完一节给我出 2 道紧贴高校真题标准的单选题，并帮我把成绩、错题和闪卡写入本地学习账本（.huixue-study/study-ledger.json），以后每次接着学都能无缝衔接。
```

---

## 二、这套工作流为什么能陪你走一辈子？

1. **换领域不换方法**：无论是 20 岁跨专业修第二学位，还是 30 岁转行 AI Agent / 金融风控，永远先用 `research-syllabus.mjs`（联网检索 GitHub 全球高星开源体系 + 本地 26 学科族谱校准）搭起「6 阶段 × 24 节主干梯子」，拒绝碎片化短视频式学习。
2. **破壁不降维**：费曼五步法只把“入口门槛”降到零基础，但到了第三阶梯立刻拉回真实公式、IRAC 请求权、实验设计 p 值/效应量与双轨独立验算，保证你学成的是真本事。
3. **进度永驻本地**：`study-ledger.json` 是纯文本 JSON，你可以直接放在个人笔记库（Obsidian / GitHub 私有仓库）里长期积累：换电脑、换 AI 模型（Claude / Cursor / Antigravity / Codex）都能瞬间接续上一次的掌握度与遗忘曲线节点。
